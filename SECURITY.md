# Security policy

The initial `0.1.x` series is maintained. This small project has no guaranteed response or remediation service-level agreement.

## Report privately

Use the repository's [private vulnerability report](https://github.com/ufodia/ghost-words/security/advisories/new) when available. If GitHub private reporting is unavailable, open a public issue requesting a private reporting channel without including exploit details or sensitive data. Do not post real recordings or transcripts in a security report unless a private channel has been agreed and the data is safe to share.

Include the version, browser, minimal reproduction, affected behavior, and proposed impact. Imported content must remain literal text, file handling must remain local, and dependencies must not introduce unannounced data transmission.

## Scope

The app processes untrusted local files in the browser. Keep your browser current. A malicious or unusually large media file can stress the browser decoder. The tool is not a malware scanner, speech-verification authority, or a sandbox for browser vulnerabilities. Do not commit recordings, generated reports, credentials, or customer data to the repository.
